# Curriculum coverage sources

## Scope

This page records external curricula used to audit product breadth. They are discovery and coverage inputs, not vendored libraries, runtime dependencies, or authority for technical claims. Canonical product content remains the concepts, roadmaps, drills, artifacts, cases, and source-backed explanations under this repository.

## Harness engineering audit

[walkinglabs/learn-harness-engineering](https://github.com/walkinglabs/learn-harness-engineering) exposed a missing progression rather than an entirely missing topic. The product already covered repository intelligence, coding-agent tools, durability, permissions, observability, and regression testing, but did not connect them into a harness-building path.

The audit resulted in:

- one Harness Engineering roadmap;
- seven missing atomic concepts around instruction topology, environment contracts, handoffs, scope, independent verification, lifecycle, and harness evaluation;
- seven progressive executable builds;
- two integrated synthesis artifacts.

The in-product [Harness engineering learning page](https://learn.significanthobbies.com/learning/harness-engineering) describes the progression. Technical claims cite primary OpenAI, Anthropic, GitHub, MCP, and standards material rather than copying course prose.

## Classic system-design audit

[liquidslr/system-design-notes](https://github.com/liquidslr/system-design-notes) was used as a chapter-level checklist against the structured case catalog. Existing cases already covered the general framework, scaling and estimation, rate limiting, consistent hashing, key-value stores, URL shortening, crawling, notifications, news feeds, chat, autocomplete, video, file storage, ride sharing, ticketing, and payments.

The uncovered reusable patterns became thirteen first-class interactive cases:

- distributed unique IDs;
- proximity search;
- nearby-friends presence;
- maps and routing;
- distributed message queues;
- metrics monitoring;
- ad-click aggregation;
- hotel reservations;
- distributed email;
- object storage;
- gaming leaderboards;
- digital wallets;
- stock exchanges.

Each case uses the existing six-stage Tradeoff engine, calculation anchors, weighted evidence rubric, failure injection, stronger answer, authoritative sources, and canonical concept/drill remediation. Cases remain practice-only until a separate worked guide passes the existing substantive publication bar.
