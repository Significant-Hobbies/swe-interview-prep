## Why

The learning OS has substantially deeper coverage than a compact external AI-engineering roadmap, but its breadth makes the dependency story harder to scan and its Systems Foundations capstone too open-ended. A clearer macro path and two missing machine-level fundamentals will turn that breadth into a more actionable interview-preparation sequence.

## What Changes

- Add a compact AI-native SWE progression on Learn: CS foundations, then DSA and AI engineering in parallel, then system-design synthesis.
- Emphasize evaluation judgment as a differentiating AI-engineering skill without adding a duplicate curriculum track.
- Add practice-backed concepts for data representation and low-level program memory.
- Add the new concepts to the Systems Foundations roadmap and generated public curriculum.
- Make a raw-socket HTTP server, with measurements and causal explanation, the default Systems Foundations synthesis project.
- Preserve all existing track, roadmap, concept, drill, review, and artifact IDs.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `expanded-learning-domains`: Strengthen the Systems Foundations curriculum contract and make the high-level AI-native learning sequence explicitly scannable from Learn.

## Impact

- Canonical curriculum data and its authoring/generation scripts.
- Learn-page presentation and a small reusable macro-path component.
- Generated public curriculum HTML, Markdown, JSON, sitemap, and agent catalogs.
- Curriculum integrity, navigation, and component tests.
- No API, database schema, production dependency, authentication, or deployment changes.
