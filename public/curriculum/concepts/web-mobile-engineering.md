# Web & Mobile Engineering

Web and native lifecycles, rendering, navigation, state, networking, offline behavior, accessibility, and release constraints.

- Difficulty: core
- Tracks: Application Engineering

## Mental model

Client engineering is lifecycle engineering. Model loading, interaction, backgrounding, connectivity, persistence, accessibility, and platform conventions explicitly.

## Practice

### Design exercise: Web & Mobile Engineering

Web and native lifecycles, rendering, navigation, state, networking, offline behavior, accessibility, and release constraints. Implement designOutline() returning non-empty values for: lifecycle, stateModel, offlineFallback. Each value must name a concrete mechanism or decision.

**Expected evidence:** A design outline with lifecycle, stateModel, offlineFallback plus an explicit failure mode or trade-off.

## Review prompts

- Why does backgrounding matter more on mobile than on web, and what does it force into the architecture?
