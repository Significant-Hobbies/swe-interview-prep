Sensing, localization, mapping, planning, control, simulation, safety, real-time loops, and hardware interfaces. Implement designOutline() returning non-empty values for: perception, planningControl, safety. Each value must name a concrete mechanism or decision.

## The mechanism

A robot closes the loop from sensing to state estimation to planning to control. Timing, uncertainty, physical safety, and simulation-to-real gaps dominate.

## Expected evidence

A design outline with perception, planningControl, safety plus an explicit failure mode or trade-off.

## Hints

- Name the failure mode before selecting the mechanism.
